**Hello MCP** is a lightweight Python-based Model Context Protocol (MCP) server developed using the official MCP Python SDK. The project demonstrates how Python functions can be exposed as tools and accessed by MCP-compatible applications.

The server provides three core functionalities: personalized greetings, mathematical calculations, and numerical data analysis. It uses the standard input/output (stdio) transport for communication with MCP clients.

## 1. Project Objectives

The main objectives of this project are:

- To understand the fundamentals of Model Context Protocol (MCP).
- To develop an MCP server using Python.
- To create and expose custom tools.
- To perform basic arithmetic operations.
- To analyze numerical datasets and generate statistical results.
- To establish communication between MCP-compatible clients and Python applications.

## 4. Environment Setup and Installation

Follow the steps below to prepare the development environment.

**Step 1: Create a Virtual Environment**

```powershell
py -m venv .venv
```

**Step 2: Activate the Environment**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Step 3: Install the MCP SDK**

```powershell
python -m pip install mcp
```

**Alternative Installation**

If PowerShell blocks environment activation, install the package using the virtual environment's Python interpreter:

```powershell
.\.venv\Scripts\python.exe -m pip install mcp
```

## 5. MCP Tool Implementation

The server exposes three independent tools, each designed to perform a specific operation.

### 5.1 get_greeting

**Purpose:** Generates a personalized greeting message based on the user's input.

**Input Parameter:**
- `name` – String representing the user's name.

**Sample Input:**

```json
{
  "name": "Students"
}
```

**Expected Output:**

```text
Hello, Students! Your first MCP tool works.
```

### 5.2 add_numbers

**Purpose:** Performs addition on two integer values and returns the calculated result.

**Input Parameters:**
- `a` – First integer.
- `b` – Second integer.

**Sample Input:**

```json
{
  "a": 10,
  "b": 20
}
```

**Expected Output:**

```text
30
```

### 5.3 analyze_data

**Purpose:** Processes a numerical list and generates a summary containing basic statistical measurements.

**Input Parameter:**
- `numbers` – A list of numerical values.

**Sample Input:**

```json
{
  "numbers": [2, 4, 6]
}
```

**Expected Output:**

```json
{
  "status": "success",
  "count": 3,
  "min": 2,
  "max": 6,
  "average": 4.0
}
```

**Statistical Parameters:**

| Parameter | Description |
|---|---|
| Status | Indicates the execution result |
| Count | Number of elements in the dataset |
| Minimum | Smallest numerical value |
| Maximum | Largest numerical value |
| Average | Mean value rounded to two decimal places |

**Error Handling:** If the input list is empty, the tool returns an error status along with an explanatory message instead of attempting the calculation.

## 6. Server Execution

Once the installation process is complete, start the MCP server from the project directory.

**Execution Command:**

```powershell
.\.venv\Scripts\python.exe server.py
```

The server operates through the MCP standard input/output (stdio) transport. It waits for requests from an MCP-compatible host and responds with the results generated by the registered tools.

## 7. Visual Studio Code Integration

The project supports integration with Visual Studio Code through an MCP configuration file.

Create `mcp.json` inside the `.vscode` directory and register the server with the identifier `helloMcp`.

The configuration launches `server.py` using the Python interpreter available in the project's virtual environment.

This allows VS Code to discover and communicate with the MCP server through its configured MCP integration.
